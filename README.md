# DOMVET — ветеринарная клиника на Ленинском

Сайт клиники на React, TypeScript и Vite.

## Локальный запуск

```bash
npm install
npm run dev
```

Проверки перед публикацией:

```bash
npm run lint
npm run build
```

## GitHub Pages

Публикация выполняется автоматически workflow из `.github/workflows/deploy-pages.yml` после push в `main`.

Сайт: https://dannniluk.github.io/DomVet-project/
